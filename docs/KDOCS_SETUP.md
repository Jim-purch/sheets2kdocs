# Kdocs 开放平台接入指南

sheets2kdocs 通过**金山文档开放平台**（官方 OpenAPI）写入智能表格，需要先创建一个应用并获得授权。

## 1. 注册开发者并认证

1. 打开 <https://developer.kdocs.cn>
2. 使用 WPS 账号登录，进入开发者后台
3. 开发者认证需要**企业资质**（营业执照）；个人开发者目前无法通过认证
4. 创建一个**服务商**（服务商会挂在你的金山文档「我的文档 → 应用」目录下）

## 2. 创建应用

1. 在服务商下「添加应用」，填写名称、描述（如 `sheets2kdocs-sync`）
2. 等待应用审核通过后，在「应用信息」页拿到：
   - `APPID`  → 填入 `.env` 的 `KDOCS_APP_ID`
   - `APPKEY` → 填入 `.env` 的 `KDOCS_APP_KEY`
3. 在应用的「回调地址」配置里添加：

   ```
   {BASE_URL}/auth/kdocs/callback
   ```

   例如服务部署在 `http://192.168.1.10:8300`，就登记
   `http://192.168.1.10:8300/auth/kdocs/callback`（协议、域名、端口必须完全一致）

## 3. 申请权限（scope）

在权限管理中申请以下 4 个权限，全部通过审核后再发布应用版本：

| scope | 用途 |
|---|---|
| `user_basic` | 读取授权用户昵称（接口要求） |
| `access_personal_files` | 浏览「我的文档」文件列表（用于文件选择器） |
| `edit_personal_files` | 写入智能表格记录/字段/数据表（核心权限） |
| `download_personal_files` | 下载能力（部分接口要求同时具备） |

## 4. 准备目标智能表格

1. 在金山文档中新建一个**智能表格**（.ksheet）
2. 在里面新建一个**数据表**（智能表格里的「+ 数据表」，不是普通工作表）
   - sheets2kdocs 的目标 sheet 必须是「数据表」类型（API 里 `sheet_type == 'db'`）
3. 记下文件 ID（备用）：打开智能表格 → 右键顶部文件标签 → 文档信息 → 文件ID

> 提示：应用创建后会出现在授权账号「我的文档 → 应用」目录下；目标表格放在「我的文档」任意位置即可被文件选择器列出。

## 5. 完成 OAuth 授权

1. 打开 sheets2kdocs 管理页面 → **Kdocs 授权**
2. 确认页面上显示的回调地址与开放平台后台登记的一致
3. 点击「打开 Kdocs 授权页面」→ 登录金山文档账号 → 同意授权
4. 跳回后自动保存令牌，页面显示「已授权，令牌有效」

备用方式（回调不方便配置时）：

- **手动粘贴 code**：打开授权链接，授权后浏览器跳转到 `redirect_uri?code=xxx`，复制 `code` 粘贴到管理页表单
- **手动粘贴 refresh_token**：若已有有效 refresh_token，直接在「手动刷新令牌」里粘贴

## 6. 令牌机制

| 令牌 | 有效期 | 说明 |
|---|---|---|
| `access_token` | 24 小时 | 到期前 5 分钟自动用 refresh_token 刷新 |
| `refresh_token` | 90 天 | 过期后需要重新走一次 OAuth 授权 |

令牌保存在服务端 SQLite（`data/sheets2kdocs.db`），请备份好 `data/` 目录。

## 7. 限流

| 应用类型 | 限额 |
|---|---|
| 测试应用 | 10,000 次/天 |
| 正式应用 | 10,000,000 次/天 |

单次记录写入按 200 条/请求分批，单次读取按 100 条/页翻页，普通场景远低于限额。

## 常见授权错误

| 现象 | 原因 / 处理 |
|---|---|
| 回调提示 redirect_uri 错误 | 后台登记的回调地址与实际访问地址不一致（协议/域名/端口都要一致） |
| code 无效 | code 只有 5 分钟有效，重新点授权链接 |
| 刷新令牌失败 | refresh_token 已过 90 天有效期 → 重新授权 |
| 接口报无权限 | 对应 scope 未申请或应用未发布新版本 |

② 获取并保存 Token

  1. 在浏览器登录 WPS 个人账号（企业账号不可用，会 403）
  2. 打开 kdocs.cn/latest → 右上角头像旁主菜单 → 「金山文档Skill」 → 复制 Token
  3. 粘贴到下面保存（保存后自动做连接测试，无需重启服务）

③ 说明

  • 同步目标：授权账号「我的文档」下的多维表格 / 智能表格（数据表）
  • 目标文件也可共享给该账号，然后用 file_id 直接填入任务表单
  • Token 仅保存在服务端数据库；管理页只显示掩码
  • 如需切换回企业 OpenAPI 模式：把 .env 的 KDOCS_BACKEND 改为 openapi 并重启
